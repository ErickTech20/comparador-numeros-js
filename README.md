# 🔍 Comparador de Números - JavaScript

Projeto interativo para demonstração de operadores de comparação em JavaScript.

## 🚀 Funcionalidades

- ✅ **8 tipos de comparações** diferentes
- ✅ **Interface moderna** e responsiva
- ✅ **Validação de entrada** (apenas números)
- ✅ **Feedback visual** com cores para true/false
- ✅ **Design responsivo** para mobile e desktop

## 📊 Operadores Implementados

1. **Igualdade** (`==`) vs **Identidade** (`===`)
2. **Diferença** (`!=`) vs **Não idêntico** (`!==`)
3. **Maior** (`>`) e **Menor** (`<`)
4. **Maior ou igual** (`>=`) e **Menor ou igual** (`<=`)

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos modernos com Flexbox e Grid
- **JavaScript** - Lógica interativa e validações
